# ADLC Loop Phase Contracts

Each loop iteration has four phases:

1. Produce: make the smallest change that could improve the criterion.
2. Evaluate: run the agreed check or collect the agreed evidence.
3. Critique: identify why the result is insufficient or risky.
4. Refine: apply only the next bounded correction.

The loop stops when the stop condition is met, max iterations are reached, or the critique finds that the criterion is wrong for the task.
