# Maintenance Checklist

For each public skill:

- [ ] folder is `skills/engineering/adlc-<name>/`
- [ ] frontmatter `name` matches folder
- [ ] description has clear triggers
- [ ] `SKILL.md` is concise and procedural
- [ ] references are one level deep
- [ ] task-critical templates live beside the skill
- [ ] large examples are central or deferred
- [ ] `agents/openai.yaml` exists and matches the skill purpose
- [ ] README lists the skill
- [ ] engineering README lists the skill
- [ ] plugin manifest lists the skill
- [ ] validation passes

For major repo decisions:

- [ ] ADR added or updated
- [ ] `AGENTS.md` updated if agent guidance changed
- [ ] `CLAUDE.md` remains a pointer to `AGENTS.md`
