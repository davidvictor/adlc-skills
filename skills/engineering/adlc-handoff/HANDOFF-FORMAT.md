# Handoff Format

```markdown
# ADLC Handoff: <Task>

## Current State

Branch, working tree state, and what has been completed.

## Source Artifacts

- PRD:
- issue/brief:
- ADRs:
- audits/reviews:

## Decisions Made

Only decisions not already captured in source artifacts.

## Open Questions

Questions that materially affect scope, safety, or value.

## Verification

Commands run, evidence captured, and what remains not verified.

## Risks And Blockers

Concrete blockers, accepted risks, or deferred work.

## Next Action

The next useful step and the ADLC skill to use.
```
