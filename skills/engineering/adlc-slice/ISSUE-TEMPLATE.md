# Issue Draft Template

```markdown
# <Short Title>

## Overview

Plain-language description of the slice and why it matters.

## Type

AFK or HITL.

## Current Behavior

What exists now.

## Desired Behavior

What should be true when this issue is complete.

## Scope

- Included behavior
- Interfaces or contracts involved
- Relevant constraints

## Non-Goals

- Adjacent work that should not be done here

## Acceptance Criteria

- [ ] Specific, independently verifiable criterion
- [ ] Edge case or blocked state handled
- [ ] Verification command or inspection named

## Verification

Commands, tests, screenshots, manual checks, or other evidence required.

## Blocked By

None, or a list of issue drafts / decisions.

## Links

PRD, plan, ADR, prototype notes, or related context.
```
