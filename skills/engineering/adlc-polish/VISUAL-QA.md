# Visual QA

Check the rendered surface, not just the code.

## Required For Meaningful Visual Work

- screenshot or browser inspection of the changed state
- supported narrow and desktop viewport checks
- no overlapping text or controls
- visible focus states
- usable hit areas
- no console errors caused by the change
- motion respects the product posture

## Focus Areas

- typography and wrapping
- nested radii
- shadows, borders, and image edges
- button and icon alignment
- dynamic content stability
- empty/error/loading states

If visual QA is blocked, state exactly what was not seen.
