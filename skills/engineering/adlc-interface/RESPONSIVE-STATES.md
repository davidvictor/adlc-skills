# Responsive And State Checklist

Render or reason through every state that can affect layout or meaning.

## Data States

- loading
- empty
- partial data
- populated
- error
- permission denied
- disabled or read-only
- success or confirmation

## Responsive Checks

- narrow mobile
- tablet or split-pane width
- normal desktop
- wide desktop, if the product supports it

## Stability Checks

- text does not overflow
- buttons do not resize awkwardly across states
- dynamic numbers do not shift layout
- media remains inspectable and relevant
- focus order still matches visual order
- fixed toolbars or footers do not cover content

If a state cannot be reproduced, name the missing fixture or access.
