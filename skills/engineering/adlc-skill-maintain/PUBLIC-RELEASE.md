# Public Release Readiness

Before calling a skill repo release-ready:

- validation passes
- every public skill appears in all manifests and indexes
- every public skill has OpenAI/Codex metadata
- README has install and quickstart guidance
- examples show the intended output quality
- ADRs capture durable suite decisions
- release notes or PR description summarize user-facing changes
- no private project assumptions are embedded in public skills
- install/use smoke checks are run or explicitly blocked

Do not create a release tag unless the user asks.
