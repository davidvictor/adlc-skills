# AGENTS.md Is Canonical Repo Guidance

Status: Accepted

## Context

This repo is used by multiple agents. `CLAUDE.md` is useful for Claude-specific compatibility, but the repository guidance should not be tied to one agent brand.

## Decision

`AGENTS.md` is the canonical guidance document for repository maintenance. `CLAUDE.md` points to `AGENTS.md` and should not duplicate the guidance.

## Consequences

Future edits to repo rules, validation policy, skill-writing standards, and packaging expectations belong in `AGENTS.md`.
