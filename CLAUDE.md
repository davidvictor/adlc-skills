Skills are organized under `skills/engineering/`.

Every public skill must:

- use the `adlc-` prefix
- include a concise `SKILL.md`
- appear in the top-level `README.md`
- appear in `skills/engineering/README.md`
- appear in `.claude-plugin/plugin.json`

Do not add repo-specific private workflow assumptions to the skills. Use universal repo conventions: `CONTEXT.md`, `docs/adr/`, and Markdown issue drafts unless a user explicitly asks to use an external tracker.
