# ADLC Architecture Checklist

An architecture artifact should cover:

- purpose and operating model
- major modules or directories
- lifecycle and orchestration flow
- runtime/install/update boundaries
- artifact ownership
- agent responsibilities and handoffs
- extension/MCP/config trust boundaries
- known limits and open decisions

Avoid speculative diagrams. Every durable claim should tie back to live code, config, docs, or an explicit user decision.
