# Visual Direction

Choose the posture from the product job, not from personal taste.

## Direction Questions

Ask only when the answer changes implementation:

- Is this for repeated work, occasional decision-making, or first impression?
- Should the user move fast, slow down, compare, or explore?
- Is the surface primarily operational, editorial, playful, commercial, or internal?
- Does the repo already have a design language that should be deepened?

## Common Postures

### Quiet Operational

Use for SaaS tools, admin panels, approvals, queues, and dashboards. Prioritize density, scan paths, stable controls, restrained color, and explicit state.

### Editorial Craft

Use for portfolios, case studies, publishing, and narrative product pages. Prioritize rhythm, typography, media, and pacing.

### Playful/Expressive

Use for games, creative tools, and low-risk delightful workflows. Prioritize responsive motion, direct manipulation, and memorable feedback.

### Brand/Landing

Use for first-impression pages. Prioritize a real product/place/person signal in the first viewport, strong hierarchy, and a visible hint of the next section.

## Anti-Patterns

- dashboard treated like a hero landing page
- generic card grids with no domain hierarchy
- decorative gradients replacing product signal
- redesigning around new primitives when existing ones are sufficient
